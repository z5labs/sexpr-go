# sexpr

A library for working with [S-expressions](https://en.wikipedia.org/wiki/S-expression) in Go.

## Install

```sh
go get github.com/z5labs/sexpr-go
```

## Usage

The tokenizer, parser, and printer are implemented in follow-up stories. Once
they land, this section will document `Tokenize`, `Parse`, and `Print` with
runnable examples.
